ⓘ データ出典

地図・データの出典

  • 3Dベースマップ： OpenFreeMap · OpenMapTiles · OpenStreetMap contributors（ODbL） 地図の道路・地名・建物などの基礎データ。表示スタイルはOpenFreeMap Positronです。
  • 3D標高・地形データ： Mapzen Terrain Tiles on AWS · Tilezen / 地形データの出典・帰属表記 アプリの標高タイルURLはAWSのTerrariumタイルです。提供元の説明ではSRTM、GMTED2010などの標高データを利用しています。
  • 2D代替地図・スポット一覧地図： CARTO · OpenStreetMap contributors 3D地図が利用できない場合のCARTO Positronと、スポット一覧ページのOpenStreetMapタイルに関する表記です。
  • 天気・日の出／日の入り： Open-Meteo API · データライセンス：CC BY 4.0 現在天気と日の出・日の入り時刻を、地図上部の環境色演出に利用します。
  • 伏見稲荷周辺のスポット・参道データ： data/spots.json · data/routes.json プロジェクト内で管理している編集データです。個々のスポット情報・写真・参道データの原典や更新日を記録する欄は現行JSONにないため、項目ごとの出典はここでは特定できません。
  • 一般道路の徒歩ルート補助： OSRM · OpenStreetMap contributors（ODbL） 伏見稲荷エリア外などで、アプリ内の参道データを補う場合にOSRMの公開ルーティングサービスを利用します。
  • 現在地・端末センサー： Geolocation API · DeviceMotionEvent · DeviceOrientationEvent 端末・ブラウザ標準の位置情報、歩行・方位センサー機能を使用します。利用可否と精度は端末・ブラウザの仕様に依存します。
  • 駅の時刻表（外部公式ページへのリンク）： 京阪・龍谷大前深草駅 · 京阪・伏見稲荷駅 · JR西日本（JRおでかけネット） 時刻表データをアプリ内に取り込むのではなく、各鉄道会社の公式ページを開きます。
  • 伏見稲荷の混雑予報（外部公式ページへのリンク）： 京都市観光協会・観光快適度 アプリ内に混雑データを取り込まず、公式ページを別画面で開きます。
  • 共有用QRコード生成： QRServer API スポット共有用QR画像の生成に利用します。
  • 地図表示ライブラリ・配信CDN： MapLibre GL JS · Leaflet · UNPKG 地図の描画・既存スポットレイヤー表示に使うソフトウェアです（地理データの提供元とは別です）。
  • 画像・動画・アイコン等のローカル素材： images/ · videos/ 素材ごとの撮影者・権利者・出典は現行データに記録されていないものがあります。公開前に素材単位で利用許諾とクレジットを確認してください。
